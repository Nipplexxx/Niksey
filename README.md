# Niksey

Приватный мессенджер для Android с end-to-end шифрованием.

## О проекте

Niksey — Android-приложение для защищённого и анонимного общения.  
Содержимое сообщений шифруется на устройстве пользователя. Сервер не имеет доступа к тексту переписки и медиафайлам.

Проект находится в стадии активной разработки. В перспективе планируется коммерческая версия с расширенным функционалом и собственной инфраструктурой.

Текущая сборка предоставляется исключительно для ознакомления, тестирования и сбора обратной связи.

## Основные возможности

- Анонимная регистрация
- Личные и групповые чаты
- Текстовые сообщения
- Фото, голосовые сообщения, видео и файлы
- End-to-end шифрование на базе Signal Protocol
- Шифрование медиафайлов на стороне клиента
- Локальный кэш с возможностью очистки
- Тёмная тема оформления

## Технические требования

- Android 7.0 и выше
- Настроенный проект Firebase (Realtime Database и Storage)
- Для сборки: Android Studio, JDK 21

## Сборка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Nipplexxx/Niksey.git
   cd Niksey
   ```
2. Откройте проект в Android Studio.
3. Добавьте свой файл `google-services.json` с данными Firebase.
4. Соберите и запустите приложение.

Без корректно настроенного Firebase приложение работать не будет.
