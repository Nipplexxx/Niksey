# Niksey

**Приватный мессенджер нового поколения**

## Описание

Niksey — это современное Android-приложение для безопасного и анонимного общения.  
В будущем проект планируется развивать как **коммерческий продукт** с премиум-функциями и собственной инфраструктурой.

Сейчас приложение доступно в открытом виде для изучения, тестирования и обратной связи.

---

## Основные возможности

- Анонимная регистрация
- Текстовые, голосовые сообщения, изображения и файлы
- Групповые чаты
- Высокий уровень приватности
- Современный тёмный/светлый дизайн

---

## Важная информация

**Niksey** — это **открытая разработка** с прицелом на коммерческое будущее.  
Приложение предоставляется **исключительно для ознакомления и тестирования**.

- Для полноценной работы требуется настройка собственной Firebase-базы.
- Автор **не несёт ответственности** за любой ущерб, возникший при использовании.
- При копировании, модификации или распространении кода **обязательно** указывать автора.
- Коммерческое использование возможно только после официального соглашения с правообладателем.
